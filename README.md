# 🚆 Railway Reservation System using Python

## 📌 Project Overview

The **Railway Reservation System** is a Python-based project that demonstrates railway ticket booking concepts, passenger details management, ticket validation, seat allocation, and reservation status tracking.

This project uses Python programming concepts to simulate a railway reservation process and retrieve railway-related information from web pages.

## 🎯 Project Objectives

* Simulate railway ticket booking and reservation.
* Store and display passenger and ticket details.
* Validate PNR numbers and seat numbers using Regular Expressions.
* Manage seat availability and allocation.
* Retrieve train schedules and passenger information using web scraping.
* Store train schedule information in text and CSV files.

## 🛠️ Tech Stack

* **Programming Language:** Python
* **Environment:** Jupyter Notebook
* **Libraries:** Requests, BeautifulSoup, Regular Expressions (`re`)
* **File Handling:** TXT and CSV
* **Concepts:** Functions, Lambda Expressions, OOP, Recursion, Exception Handling, Web Scraping

## ✨ Key Features

### 1. Ticket Booking

* Store passenger names, train names, seat numbers, and ticket fares.
